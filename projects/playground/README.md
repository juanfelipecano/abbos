# Abbos playground

The docs and showcase site for the Abbos library: live playgrounds, examples with their real
source, API tables and accessibility notes for every component.

```bash
npm run dev        # watch-build the library and serve this app
ng test playground # unit tests
```

Full documentation lives in [`docs/`](docs/README.md):

- [Adding a directive or pipe](docs/adding-a-directive-or-pipe.md)
- [Building blocks](docs/building-blocks.md)
